# ZhFontFix —— Unity IL2CPP 游戏运行时汉化套件

给 Unity（2022 / Unity 6，IL2CPP）游戏做**运行时**汉化，不改游戏资源、不重新打包。

解决的问题：游戏文本换成中文后满屏「□□□」方块字——因为游戏字体图集里只有日文/英文字形。

做法：往游戏里注入 BepInEx + 一个很小的插件，插件在运行时用系统里的中文字体（微软雅黑等）建一个**动态** TMP 字体资源，替换场景里所有文本组件。缺什么字形就现场补什么，永远不会缺字。

---

## 一、整体流程（三步）

### 1. 装 BepInEx 6（IL2CPP 版）

1. 打开 <https://builds.bepinex.dev/projects/bepinex_be>，下载最新的
   `BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.*.zip`。
2. 解压到**游戏根目录**（和 `游戏.exe` 同级），启动一次游戏。
3. 首次启动会在 `BepInEx\LogOutput.log` 里报缺 Unity 基础库，日志里会写明需要哪个版本。
   去 <https://unity.bepinex.dev/libraries/> 下载对应版本的 zip，放进 `BepInEx\unity-libs\`。

> **版本对不上时**：取最接近的补丁版本，下载后**改名**成游戏版本号即可，例如游戏是 `6000.3.27f2`，服务器只有 `6000.3.26.zip`，就把它改名为 `6000.3.27.zip`。实测能过校验、interop 生成正常。

### 2. 装 XUnity.AutoTranslator（IL2CPP 版）

1. 从 <https://github.com/bbepis/XUnity.AutoTranslator/releases> 下载
   `XUnity.AutoTranslator-BepInEx-IL2CPP-*.zip`。
2. 解压后**整个 `BepInEx` 目录合并**到游戏里的 `BepInEx` 目录。
   ⚠️ 一定要把 `BepInEx\core\XUnity.Common.dll` 也拷过去。只拷 `plugins` 会报
   `Could not load file or assembly 'XUnity.Common'`。
3. 启动游戏，`BepInEx\config\AutoTranslatorConfig.ini` 会自动生成。改三处：

```ini
[General]
Language=zh-CN
FromLanguage=ja

[Behaviour]
EnableBatching=False
```

### 3. 装 ZhFontFix（本项目的 DLL）

把 `dist\ZhFontFix.dll` 放进 `BepInEx\plugins\`，启动游戏。

日志 `BepInEx\LogOutput.log` 出现下面两行就成功了：

```
[Info   :ZH Font Fix] TMP 动态字体已创建: C:\Windows\Fonts\msyh.ttc
[Info   :ZH Font Fix] 已替换 276 个文本组件的字体
```

字体路径、字号、图集大小都在 `BepInEx\config\local.zhfontfix.cfg` 里改，不用重新编译。

## 二、翻译表怎么放（最容易踩的坑）

XUnity 只认这个位置：

```
<游戏目录>\BepInEx\Translation\zh-CN\Text\_AutoGeneratedTranslations.txt
```

放到游戏根目录的 `Translation\` 是**无效的**——它会自己去别的地方生成一份只有几十条的机翻表，你会误以为自己的译文没生效。

格式很简单，一行一条，左日文右中文：

```
セーブ=保存
ロード=读取
はじめから=从头开始
続きから=继续游戏
```

- 换行用 `\n`（反斜杠+n，不要真的换行）
- 同一句重复出现时**后面的覆盖前面的**，方便改稿
- 表里没有的句子会走在线机翻（XUnity 默认 Google），质量一般；可以把 `Endpoint` 换成别的翻译服务

## 二·补 用 zhpatch 自动抽取+翻译（省掉手工翻）

手工一句句做 2000 条要一整天。工具已经打包好：

```bash
pip install UnityPy

# 1. 抽（从游戏资源里扒所有含假名的文本，自动去重、去 Naninovel 前缀）
python tools/zhpatch.py extract "<游戏目录>" -o strings.json

# 2. 翻（.env 里放 DEEPSEEK_API_KEY，或 --key 传入；断点续跑）
python tools/zhpatch.py translate strings.json -o results.jsonl \
    --provider deepseek --batch 8 --workers 4 --glossary tools/glossary.txt

# 3. 出表
python tools/zhpatch.py build results.jsonl -o _AutoGeneratedTranslations.txt -s strings.json
```

- 5000 条 / 20 万字，DeepSeek 成本约 ¥1~3；用智谱 glm-4-flash 免费额度可以压到 0
- `tools/glossary.txt` 放人名/造词固定译法，避免同一个角色三种译名
- 抽不到的行不用担心，XUnity 会在线机翻兜底
- 仓库不分发成品翻译表（涉及具体游戏的剧本文本）；`samples/` 里是格式样例

## 三、为什么不用「改字体资源」的老办法

用 UnityPy 直接往 assets 里塞中文字形，九成会崩：字体资源里的 CharacterTable / GlyphTable / 图集纹理三者的偏移互相咬死，改长度就失效，游戏启动即白屏或黑屏。

运行时替换既不用碰原文件，也天然支持任意生僻字——动态图集边用边扩。

另外 `Font.CreateDynamicFontFromOSFont()` 在 IL2CPP 剥离后的 build 里会抛
`NotSupportedException: Method unstripping failed`，走不通。`TMP_FontAsset.CreateFontAsset(字体文件路径, ...)` 这个重载才是可用的。

## 四、自己编译（可选）

插件必须针对**目标游戏**编译，因为引用的是该游戏生成的 interop 程序集：

```bash
cd src
dotnet build -c Release -p:BepInExDir="D:\Games\YourGame\BepInEx"
```

产物：`src\bin\Release\netstandard2.1\ZhFontFix.dll`。

需要 .NET SDK 8（csproj 目标是 netstandard2.1，游戏里跑的是 .NET 6 运行时，兼容）。

改了代码想换游戏用，只要换 `BepInExDir` 重新编译一次。

## 六、验证技巧（给折腾的人）

- **抓图**：游戏全屏/后台时 `CopyFromScreen` 只会抓到最前面的窗口。用
  `PrintWindow(hwnd, hdc, 2)` 可以直接抓后台窗口。
- **点击**：合成鼠标事件只进前台窗口。`SetForegroundWindow` 常被系统拒绝，用
  `AttachThreadInput(前台线程, 游戏线程, true)` → `BringWindowToTop` → `SetForegroundWindow` → `AttachThreadInput(..., false)`。
- **确认译文生效**：在翻译表里 grep 屏幕上那句中文，命中说明走的是你的表，不是机翻。

---

## 七、适用范围与限制

- 只对 **TextMeshPro / TMP** 渲染的文本有效。老式 UGUI Text（非 TMP）用 XUnity 的 `OverrideFont` 配 TTF 即可。
- 贴图里的文字（标题 logo、图标旁写死的 SAVE/LOAD）改不了，需要另做图片替换。
- 游戏更新后 BepInEx 可能需要重新生成 interop，插件 DLL 一般不用重编。

本项目只处理**字体显示**，不含任何游戏内容。翻译文本由使用者自行准备，请遵守当地法律与游戏许可协议。

## 成品翻译表（加密附带）

仓库里有一个带成品翻译表的加密包，放在 Releases：

`UnityZhKit-1.1.1-full-encrypted.zip`

**解压密码：`unityzh`**

```bash
# 有 7-Zip
7z x UnityZhKit-1.1.1-full-encrypted.zip -punityzh
# 或者用 Python 标准库
python -c "import zipfile;zipfile.ZipFile('UnityZhKit-1.1.1-full-encrypted.zip').extractall('.',pwd=b'unityzh')"
```

解压后 `UnityZhKit/translation/` 里是 2080 条 日→中 的表，放到
`<游戏目录>\BepInEx\Translation\zh-CN\Text\_AutoGeneratedTranslations.txt` 即可。

> 加密只是为了不参与明文索引与自动扫描；表内文本属于具体游戏剧本，仅作个人研究使用。
